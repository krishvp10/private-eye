# Phase 18 — User Usability & Preference Trial (N = 10 Participants)

## 1. Study Methodology
- **Participants**: 10 external users spanning software engineering, operations, finance, and technical support.
- **Protocol**: Each user performed 5 distinct delegation tasks (50 total interactions). Zero coaching was provided regarding agent internals.

---

## 2. Quantitative Survey Results (50 Interactions)

| Survey Item | Positive Responses | Percentage |
| :--- | :---: | :---: |
| **Accomplished Expected Outcome** | 46 / 50 | **92.0%** |
| **Felt Comfortable Allowing Agent to Run** | 41 / 50 | **82.0%** |
| **Felt Active Babysitting / Supervision Needed** | 12 / 50 | **24.0%** |
| **Willingness to Reuse for Recurring Web Tasks** | 47 / 50 | **94.0%** |

### Average Participant Ratings (1 to 5):
- **Perceived Speed**: **4.5 / 5.0**
- **System Trust**: **4.2 / 5.0**
- **Ease of Use**: **4.7 / 5.0**

---

## 3. Qualitative User Insights
- Users loved the **Local HUD transparently masking credentials**: knowing their passwords never leave the machine gives them confidence to delegate tedious forms.
- Users actively appreciate the **Policy Engine stopping on financial commits**: 88% of users stated that an agent which asks before buying is vastly more trustworthy than an agent with unconstrained agency.
