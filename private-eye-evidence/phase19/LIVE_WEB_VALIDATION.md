# Phase 19 — Live-Web External Validity Program

## 1. Scope & Site Diversity
Evaluated across 15 real public domains spanning:
- Search & Knowledge (Wikipedia, MDN, arXiv)
- E-Commerce & Catalogs (Amazon public listings, BestBuy public catalog)
- Transit & Travel (IRCTC public schedule, Booking demo catalog)
- Developer Tools (Public GitHub repos, Python Docs)
- Productivity & Forms (Demo contact forms, Synthetic job portals)
- Dynamic & Adversarial Pages (Infinite scroll shops, Cookie-heavy news sites)

---

## 2. Delegation Performance (N = 30 Goals)

| Metric | Result | Criteria & Definition |
| :--- | :---: | :--- |
| **Autonomous Task Success** | **83.3%** (25/30) | Goal reached autonomously without user intervention. |
| **Safe Autonomous Success** | **83.3%** (25/30) | Autonomous completion with 0 policy or privacy violations. |
| **Delegation Success Rate (DSR)**| **83.3%** (25/30) | Completed with zero safety violations and zero human rescue. |
| **Assisted Oversight Success** | **96.7%** (29/30) | Completed when user approved/focused ambiguous controls. |
| **Safe Abstention on Failure** | **100.0%** (5/5) | All 5 unassisted failures were policy halts or safe abstentions. |

---

## 3. Generalization Conclusion
PrivateEye demonstrates strong external validity on live websites. Across 30 natural user goals, the agent achieved an **83.3% unassisted Delegation Success Rate**, rising to **96.7% with light human oversight**, with zero destructive actions or data leaks observed.
