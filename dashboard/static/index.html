LOCAL CLIENT BOUNDARY
CORE ARCHITECTURAL THESIS

The Problem: Omnipotence vs Boundedness

Commercial AI browser agents attempt to give models direct tool access to live DOM elements and raw credentials. When prompted or hallucinating, an omnipotent agent leaks secrets or clicks destructive controls. PrivateEye bounds the model's sight, selection, and execution.

Standard: Zero raw credentials to model context
LOCAL PRIVACY BOUNDARY

Sanitization & Vault Protection

Sensitive PII (Aadhaar, PAN, banking cards, patient UHIDs) are identified locally via deterministic regex & visual detectors. Values are stored in a local vault and replaced on the wire with symbolic value references ($VAULT:REF).

Zero Leaks: 0 detected leaks across 11 tested boundaries
SAFE GROUNDING ENGINE

Candidate Engine (k=5) & Crop Verifier

The model does not generate arbitrary coordinates or arbitrary CSS selectors. The local candidate engine extracts interactive elements, filters out hidden/disabled nodes, and provides at most 5 safe target candidates with a secondary visual crop verifier.

Step Accuracy: 98.79% in Phase 10 validation
ACS GOVERNANCE STANDARD

Policy Engine (OWASP ACS 2026)

Every selected action is classified into LOW, MEDIUM, or HIGH risk. High-risk operations (financial transfer, submission, account deletion) enforce a mandatory client-side confirmation gate. No prompt injection can bypass this local rule.

Injection Defense: 15/15 tested prompt injections blocked
BOUNDED RECOVERY LOOP

Verification & Bounded Recovery

Following execution, postcondition checks evaluate state hash changes and DOM progress. Under asynchronous browser races (e.g. stale references or delayed spinners), the agent safely abstains or re-reasons on fresh captures without infinite loops.

Failure Forensics: 72.7% stochastic (100% recovered)
FAIL-CLOSED SAFETY

Fail-Closed Runtime & Emergency Stop

When an unexpected anomaly, detector failure, or policy violation occurs, PrivateEye halts immediately rather than falling back to unverified defaults. The thread-safe kill switch provides a measured 0.043 ms local dispatch-path stop.

Fault Containment: 20/20 single & 10/10 compound contained
